# Космос Phase — инструкция

## Игрокам

**Как попасть в космос.** Поднимитесь в обычном мире выше **Y 2000** на элитрах с фейерверками.
Последние 64 блока над хотбаром видно «Космос через N бл». Вы появитесь в космосе над Землёй.

**Как вернуться.** Два способа:
1. Влететь в куб Земли — сразу окажетесь на поверхности, там, откуда улетали.
2. Спуститься на 2000 блоков ниже плоскости системы (Y −2000). Это **вход в атмосферу**: вы падаете
   с высоты ~1940 туда, откуда улетали. Разбиться нельзя, но обшивка раскаляется.

**Вход в атмосферу и нагрев.** Любой быстрый спуск выше Y 700 греет. Над хотбаром шкала «Нагрев» и температура.
Вокруг — плазма, огненное кольцо по краям экрана, искры, дым, гул пламени. На сильном нагреве
(шкала почти полная) раз в 2 секунды ненадолго загораетесь — примерно полсердца. Как не сгореть:
* раскрыть элитры — торможение греет вдвое меньше и охлаждает;
* выпить зелье огнестойкости — урона не будет совсем;
* в креативе и наблюдателе нагрева нет.

**В космосе.**
* Невесомость: полёт включён всегда. Пробел — вверх, Shift — вниз.
* **Разгон:** бег по прямой разгоняет до ~140 бл/с в системе и ~240 бл/с в дальнем космосе. Вокруг
  взгляда тянутся световые линии гиперпрыжка.
* Над хотбаром — на что вы смотрите и сколько до этого. Посмотрите на любую точку — увидите, что это.
* **Миры планет:** влетите в куб планеты или спутника. У самого портала его затягивает воронка из колец и пыли.
  Обратно — подняться к верху мира планеты (Y ~231).
* **Опасно:** Солнце и звёзды жгут, чёрная дыра Ёми притягивает (за горизонтом — кротовая нора к TON 618,
  ядро квазара ведёт домой), пульсар Кагура облучает.
* **События** — каждые 15 минут с вероятностью ~60%, за минуту приходит предупреждение в чат:
  метеорный поток (рядом падают метеориты с рудой), солнечная вспышка, Затмение Фазы, великая комета,
  блуждающая планета, гамма-всплеск TON 618. На обычный мир события не влияют.

**Небо Земли и созвездия.**
* Солнце и Луна на небе — наши, кубические, у Луны пиксельные фазы.
* По пути Солнца видны планеты: Венера (яркая, всегда недалеко от Солнца — вечером и утром), Меркурий
  (низко в сумерках), красный Марс, яркий Юпитер, жёлтый Сатурн и фиолетовая мерцающая **Флорана**.
  Они стоят там, где реально находятся на орбитах мода, и со временем сдвигаются.
* Кометы, подлетевшие к Солнцу, видно с Земли — с хвостом от Солнца.
* **12 созвездий Phase:** Кицунэ, Тории, Фудзи, Цуру, Кои, Рю, Катана, Сакура, Тōро, Усаги, Оги, Кольцо Затмения.
  Звёзды созвездий крупнее обычных. За 12 игровых дней небо делает круг: у каждого дня своё **созвездие
  сезона** (`/space sky`). В космосе — те же созвездия.
* **Изучение:** ночью под открытым небом (в космосе — когда угодно) наведите **подзорную трубу** на созвездие
  и держите ~8 секунд. Над хотбаром идёт шкала, на небе проступают линии. Изученное созвездие навсегда
  рисуется линиями, в чат приходит его легенда, дают опыт. Все 12 — звание **Звездочёт** на весь сервер и 10 уровней.
* **Телескоп:** подзорная труба, наведённая на планету, называет её и расстояние; первое наблюдение — в атлас.
* **Атлас** (`/space atlas`): созвездия, планеты в телескопе, посещённые миры (за каждый новый мир — опыт),
  объекты дальнего космоса, до которых долетели.

### Хаос затмения (по команде админа)

Затмение запускает админ. Центр — кратер Фудзи (с модом карты Phase World), над всей картой идёт полоса с фазой и временем.

* **Предвестие → Тень.** Чёрный диск Луны наползает на Солнце, земля дрожит, над кратером дым и чёрное «око»,
  по склонам Фудзи бьют молнии. Чем дальше от Фудзи, тем меньше закрыто Солнце: у края карты затмение частное.
* **Хаос (полная фаза).** Темнеет, по горизонту — закатное зарево, днём видны звёзды и планеты, у Солнца корона.
  * **Луч из кратера** — столб света в небо. Встаньте в него в кратере: он поднимает вверх, до высоты 2000 и дальше
    в космос. Присесть — выйти из луча (медленное падение, разбиться нельзя).
  * **Ударные волны** расходятся кольцами от кратера по всей карте. Волна отбрасывает и ранит;
    **щит в блоке** гасит её полностью, **присед** — почти полностью.
  * **Осколки затмения** падают с неба вокруг игроков в тени (аметистовые осколки, изредка — друзы кристалла затмения).
  * **Фантомы** нападают в темноте (до 3 на игрока), после затмения рассеиваются.
  * Молнии рядом (только вспышка и гром), извержение бокового кратера Хоэй.
  * **«Кольцо Затмения»** — это созвездие можно изучить только во время затмения (днём, в тени) или в космосе во время «Затмения Фазы».
* **Бриллиантовое кольцо.** Вспышка на краю Солнца, последняя большая волна, фантомы исчезают.
* **Атлас:** «Свидетель затмения» (пробыть в полной тени шестую часть затмения — минуту из шести), «Луч затмения»
  (подняться по лучу на 500 блоков), «Щит против волны». Смотрите в `/space atlas`.

**Команды для всех:** `/space` (инструкция в игре), `/space info`, `/space atlas`, `/space sky`, `/space events`, `/space list`.
То же самое — `/космос`.

## Админам (op 2+)

| Команда | Что делает |
|---|---|
| `/space go [игроки]` | в космос к Земле |
| `/space home [игроки]` | домой на Землю, сразу на поверхность |
| `/space fall [игроки]` | домой через вход в атмосферу (падение с нагревом) |
| `/space tp <тело> [игроки]` | в космос к телу: `mars`, `florana`, `saturn`, `yomi`, `ton618`, `amaterasu`, `sun`… (Tab подсказывает) |
| `/space land <тело> [игроки]` | сразу на поверхность мира тела |
| `/space open` | открыть космос |
| `/space close` | закрыть космос: вылет на 2000 перестаёт работать, всех из космоса и с планет возвращает на Землю (кроме креатива и наблюдателей) |
| `/space reload` | перечитать `config/phasespace.json` |
| `/space eclipse start [секунды]` | хаос затмения над Фудзи (по умолчанию 360 с, можно 60–3600). Ставит полдень и ясную погоду |
| `/space eclipse here [секунды]` | то же, но центр — где вы стоите |
| `/space eclipse stop` | остановить затмение |
| `/space eclipse` | что сейчас идёт и где центр (доступно всем) |
| `/space events` | расписание событий на 2 часа |
| `/space list` | все id тел и координаты дальнего космоса |

Без игроков команда действует на вас самих. Открыт космос или закрыт, сохраняется в конфиг и переживает перезапуск.

Если в конфиге `playerCommands: true`, то `/space go`, `/space home` и `/space fall` для себя может вызвать любой игрок
(когда космос закрыт, `go` им не сработает).

## Конфиг `config/phasespace.json`

| Поле | По умолчанию | |
|---|---|---|
| `spaceOpen` | true | открыт ли космос (меняется командами open/close) |
| `playerCommands` | false | игроки могут сами go/home/fall |
| `overworldExitY` | 2000 | высота вылета в космос |
| `spaceReturnY` | −2000 | ниже — возврат на Землю |
| `atmosphereY` | 700 | выше этой высоты быстрый спуск раскаляет |
| `reentryDamage` | true | нагрев обжигает |
| `flySpeed` | 0.11 | полёт в космосе |
| `warpMaxSystem` / `warpMaxDeep` | 0.22 / 0.45 | предел разгона |
| `starHeat` | true | звёзды, квазар, пульсар жгут |
| `events` / `meteorites` | true / true | события и метеориты из блоков |
| `navigation` | true | подсказки над хотбаром |
| `quality` | 1 | клиент: 0–2, количество эффектов |
| `skyWithShaders` / `lensFlare` | true / true | клиент: своё небо при шейдерах, блики от Солнца |
| `eclipseSeconds` | 360 | длительность затмения по умолчанию |
| `eclipseX` / `eclipseZ` | 0 / 0 | центр затмения, если Phase World не стоит |
| `eclipseSetNoon` | true | при запуске — полдень и ясно |
| `eclipseWaves` / `eclipseWaveDamage` | true / true | ударные волны и их урон |
| `eclipseBeam` | true | луч из кратера поднимает игроков |
| `eclipseCrystals` / `eclipseMobs` | true / true | дождь осколков, фантомы |
| `eclipseDarkness` | 1.0 | клиент: насколько темнеет мир (0–1) |
