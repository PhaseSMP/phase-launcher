# Космос Phase — инструкция

## Игрокам

**Как попасть в космос.** Поднимитесь в обычном мире выше **Y 2000** на элитрах с фейерверками.
Последние 64 блока над хотбаром видно «Космос через N бл». Вы появитесь в космосе над Землёй.

**Как вернуться.** Два способа:
1. Влететь в куб Земли — сразу окажетесь на поверхности, там, откуда улетали.
2. Спуститься на 2000 блоков ниже плоскости системы (Y −2000). Это **вход в атмосферу**: вы падаете
   с высоты ~1940 туда, откуда улетали. Разбиться нельзя, но обшивка раскаляется.

**Вход в атмосферу и нагрев.** Любой быстрый спуск выше Y 700 греет. Над хотбаром шкала «Нагрев» и температура.
Вокруг — плазма, огненное кольцо по краям экрана, искры, дым, гул пламени. На сильном нагреве
(шкала почти полная) раз в 2 секунды ненадолго загораетесь — примерно полсердца. Как не сгореть:
* раскрыть элитры — торможение греет вдвое меньше и охлаждает;
* выпить зелье огнестойкости — урона не будет совсем;
* в креативе и наблюдателе нагрева нет.

**В космосе.**
* Невесомость: полёт включён всегда. Пробел — вверх, Shift — вниз.
* **Разгон:** бег по прямой разгоняет до ~140 бл/с в системе и ~240 бл/с в дальнем космосе. Вокруг
  взгляда тянутся световые линии гиперпрыжка.
* Над хотбаром — на что вы смотрите и сколько до этого. Посмотрите на любую точку — увидите, что это.
* **Миры планет:** влетите в куб планеты или спутника. У самого портала его затягивает воронка из колец и пыли.
  Обратно — подняться к верху мира планеты (Y ~231).
* **Опасно:** Солнце и звёзды жгут, чёрная дыра Ёми притягивает (за горизонтом — кротовая нора к TON 618,
  ядро квазара ведёт домой), пульсар Кагура облучает.
* **События** — каждые 15 минут с вероятностью ~60%, за минуту приходит предупреждение в чат:
  метеорный поток (рядом падают метеориты с рудой), солнечная вспышка, Затмение Фазы, великая комета,
  блуждающая планета, гамма-всплеск TON 618. На обычный мир события не влияют.

**Команды для всех:** `/space` (инструкция в игре), `/space info`, `/space events`, `/space list`.
То же самое — `/космос`.

## Админам (op 2+)

| Команда | Что делает |
|---|---|
| `/space go [игроки]` | в космос к Земле |
| `/space home [игроки]` | домой на Землю, сразу на поверхность |
| `/space fall [игроки]` | домой через вход в атмосферу (падение с нагревом) |
| `/space tp <тело> [игроки]` | в космос к телу: `mars`, `florana`, `saturn`, `yomi`, `ton618`, `amaterasu`, `sun`… (Tab подсказывает) |
| `/space land <тело> [игроки]` | сразу на поверхность мира тела |
| `/space open` | открыть космос |
| `/space close` | закрыть космос: вылет на 2000 перестаёт работать, всех из космоса и с планет возвращает на Землю (кроме креатива и наблюдателей) |
| `/space reload` | перечитать `config/phasespace.json` |
| `/space events` | расписание событий на 2 часа |
| `/space list` | все id тел и координаты дальнего космоса |

Без игроков команда действует на вас самих. Открыт космос или закрыт, сохраняется в конфиг и переживает перезапуск.

Если в конфиге `playerCommands: true`, то `/space go`, `/space home` и `/space fall` для себя может вызвать любой игрок
(когда космос закрыт, `go` им не сработает).

## Конфиг `config/phasespace.json`

| Поле | По умолчанию | |
|---|---|---|
| `spaceOpen` | true | открыт ли космос (меняется командами open/close) |
| `playerCommands` | false | игроки могут сами go/home/fall |
| `overworldExitY` | 2000 | высота вылета в космос |
| `spaceReturnY` | −2000 | ниже — возврат на Землю |
| `atmosphereY` | 700 | выше этой высоты быстрый спуск раскаляет |
| `reentryDamage` | true | нагрев обжигает |
| `flySpeed` | 0.11 | полёт в космосе |
| `warpMaxSystem` / `warpMaxDeep` | 0.22 / 0.45 | предел разгона |
| `starHeat` | true | звёзды, квазар, пульсар жгут |
| `events` / `meteorites` | true / true | события и метеориты из блоков |
| `navigation` | true | подсказки над хотбаром |
| `quality` | 1 | клиент: 0–2, количество эффектов |
| `skyWithShaders` / `lensFlare` | true / true | клиент: своё небо при шейдерах, блики от Солнца |
