# Phase World и шейдеры (Iris: Photon, Complementary, BSL, Bliss…)

Мод работает с шейдерами без настроек. Что делается автоматически:

1. **Листва и растения качаются на ветру.** Листва момидзи, гинкго и глицинии лежит в теге
   `minecraft:leaves`. Хиганбана, светящийся папоротник и дикие растения лежат в `minecraft:small_flowers`,
   культуры в `minecraft:crops`. Photon читает эти теги через Iris (нужна свежая версия Iris с поддержкой
   тегов в `block.properties`), поэтому наши растения качаются так же, как ванильные.
2. **Свечение (LabPBR).** У светящихся блоков есть карты `_s.png` с каналом emission: у хикаригокэ,
   светогриба, светящегося папоротника, лозы духов, кристалла затмения и фонаря торо.
   В Photon включите `Materials → Specular Mapping`, после этого они светятся сами. Яркость регулирует
   `Emission Strength` в том же разделе.
3. **Туман и частицы биомов** (лес духов, парящие скалы, Дзигоку, светящиеся глубины) заданы через
   атрибуты окружения Minecraft 26.3. Шейдеры с собственным туманом их тоже учитывают.

## Цветной свет в Photon (по желанию)

Photon назначает цветной свет блокам по их id в файле `shaders/block.properties` внутри шейдерпака.
Распространять изменённый Photon нельзя, поэтому эти строки вы дописываете в свою копию сами:
откройте zip шейдерпака, найдите строки ниже и допишьте id через пробел в конец строки.

```
# слабый белый свет (как у светящегося лишайника)
block.10034 = ... phaseworld:hikari_moss phaseworld:hikari_moss_carpet phaseworld:lumen_fern phaseworld:spirit_vine
# сильный белый свет
block.10032 = ... phaseworld:glowcap_block phaseworld:glowcap
# золотой свет (фонари)
block.10035 = ... phaseworld:stone_lantern
# аметистовый свет
block.10055 = ... phaseworld:eclipse_crystal_cluster phaseworld:eclipse_crystal_block
```

Сохраните zip и перезагрузите шейдеры (клавиша R в меню шейдеров).
